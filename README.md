# Deadpan Forecasts for Cities That Do Not Exist

One line, at most 160 characters: a weather forecast for a city that does not exist — absurd but believable, read like a real forecaster would read it, with a concrete image, number or detail that makes the invented place feel real.

## Entry

> Hailstones the size of golf balls are forecast for Pebbleford this evening; the golf club has asked that none be returned to the course.

## How it works

`main.py` writes the entry line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
